## 1. 四个环节的业务差异

| 环节 | 业务目标 | 时间尺度 | 主要系统 | 主要协议 | 网络形态 |
|---|---|---|---|---|---|
| **发电** | 把一次能源变成电（机组可控、稳发满发） | 毫秒（保护/调节）→ 分钟（AGC）→ 小时（经济调度） | DCS、SIS、NCS/升压站监控、AGC/AVC 子站、水电厂计算机监控、新能源场站控制系统 | 厂商专有、Modbus、OPC DA/UA、IEC 104、GOOSE（升压站） | 厂内 OT 局域网 + 升压站 |
| **输电** | 把电送到负荷中心（线路与变电站可控可观测） | 毫秒（保护）→ 秒（远动）→ 分钟（调度） | 调度自动化 EMS/SCADA、广域测量 WAMS/PMU、雷电/覆冰监测、输电线路在线监测 | ICCP/TASE.2、IEC 104、DNP3、C37.118 | 调度数据网（纵向，站间 + 主站） |
| **变电** | 电压变换与电能分配（保护可靠、开关可控） | **毫秒（GOOSE 跳闸）** → 秒（遥测上送） | 变电站自动化系统（SAS）、保护信息系统、故障录波、站用电与辅控 | **IEC 61850（MMS/GOOSE/SV）**、IEC 104/DNP3 远动 | 站内二层过程层/站控层网络（VLAN 划分） |
| **配电** | 把电送到用户（故障隔离、快速复电） | 秒（馈线自动化）→ 分钟（复电） | 配网自动化主站（DMS/SCADA）、配电终端（DTU/FTU/TTU）、用电信息采集、充电设施运营平台 | DNP3、IEC 104、Modbus、无线专网/4G、DL/T645 | 主站 + 大量分散终端（无线/光纤混合） |

**关键不对称**：元件物理约束把不同环节的“可接受延迟”拉到不同量级。
变电保护通道是 **毫秒级**（GOOSE 无签名即因签名开销无法满足预算）；配电是 **秒级**；
管理信息大区是分钟级。这决定了各环节可部署的安全机制强度不同。

## 2. IT/OT 边界与安全分区

### 2.1 中国电力监控系统安全防护框架（分区与隔离）

| 分区 | 别称 | 典型系统 | 隔离要求 |
|---|---|---|---|
| **安全 I 区** | 控制区 | SCADA/EMS、AGC/AVC、变电站自动化、继电保护、配网自动化主站、电厂 DCS/计算机监控 | 与 II 区逻辑隔离/防火墙；与 III 区**横向物理隔离** |
| **安全 II 区** | 非控制区 | 水情、气象、电能量计量、PMU/功角测量、保护信息子站、故障录波、在线监测 | 同上 |
| **安全 III 区** | 管理信息大区 | 生产管理、检修管理、OA、报表、图纸与定值单库 | 经**正/反向隔离装置**单向受控互通 |
| （互联网区） | IV 区 | 对外门户、移动应用、客户服务 | 与 III 区边界防护 |

三条硬边界（决定攻击路径的“必经关口”）：

1. **横向隔离**：I/II 区 ↔ III 区 之间部署**电力专用横向单向安全隔离装置**（正向/反向），
   协议被剥离为文件级/字节级摆渡，常规 TCP 穿透在此终止。
2. **纵向认证**：主站 ↔ 厂站 的广域纵向通道两端部署**纵向加密认证装置**，做认证与加密；
   这是“伪造主站”类攻击必须面对的关口。
3. **网络专用**：调度数据网与综合数据网物理/逻辑分离。

### 2.2 IT/OT 融合后的现实边界（防御薄弱点）

| 薄弱点 | 说明 |
|---|---|
| 双网卡/双归属 | 工程师站、报表机、外委运维笔记本同时接 OT 与办公网 |
| 移动介质 | 检修介质、定值单、录波文件在两侧流转 |
| 远程运维 | 厂商远程诊断通道、VPN、（历史遗留）调制解调器 |
| 边界设备的“管理面” | 隔离装置、防火墙、纵向加密装置自身的 Web/SNMP 管理口与弱口令 |
| 无线回传 | 配网终端 4G/无线专网：终端侧普遍无强认证，且常与主站策略不对称 |
| 第三方系统 | 充电桩运营平台、光伏集中监控平台等“云侧”直连 OT |

> 靶场参照：GRFICSv3 用一台 `router`（双网段 `192.168.95.200` / `192.168.90.200`）承担
> OT↔IT 关口，OT 侧放 `plc`(`192.168.95.2`)、`EWS`(`192.168.95.5`)、`simulation`(`192.168.95.45`)，
> IT/DMZ 侧放 `HMI`(`192.168.90.107`)、`kali`(`192.168.90.6`)、`caldera`(`192.168.90.250`)、
> `wazuh`(`192.168.90.20`)。该拓扑把“从 IT 攻击机出发，经关口进入 OT，最终影响 PLC 与物理过程”
> 的完整链条显式化，可作为电力场景线性化验证环境。

## 3. 典型系统

| 系统 | 全称/别称 | 环节 | 核心功能 | 攻击价值的定位 |
|---|---|---|---|---|
| **DCS** | 分散控制系统 | 发电 | 机组主辅机闭环控制、模拟量调节 | 直接操纵机组；失守 = 停运/设备损坏 |
| **SIS** | 厂级监控信息系统 / 安全仪表系统 | 发电 | 前者为厂级性能计算与实时数据库；后者为安全联锁 | 名称冲突需按上下文判定；安全仪表系统失守 = **Loss of Safety** |
| **NCS** | 网络控制系统（升压站监控） | 发电 | 升压站开关与保护监视控制 | 与电网侧接口 |
| **SCADA** | 数据采集与监视控制 | 全环节 | 遥测/遥信采集、遥控/遥调下发、告警 | 通用“总控台” |
| **EMS** | 能量管理系统 | 输电（调度） | 状态估计、潮流、AGC/AVC、调度员潮流 | 区域级影响；伪造遥测可误导状态估计 |
| **SAS** | 变电站自动化系统 | 变电 | 站控层（后台/远动）+ 间隔层（保护测控）+ 过程层（MU/智能终端） | GOOSE/SV/MMS 三面同时暴露 |
| **DMS/DAS** | 配网管理系统 / 配网自动化 | 配电 | 馈线自动化、故障隔离与复电、拓扑分析 | 影响面广（点多、面广、单点防护弱） |
| **TMR/计量** | 电能量计量系统 | 发/输/配 | 关口与关口的电量结算 | 直接经济影响 |
| **WAMS/PMU** | 广域测量系统 | 输电 | 同步相量采集（C37.118） | 动态监测；伪造相量影响稳定判断 |
| **保护信息系统** | 保信子站/主站 | 变电 | 保护装置定值与动作信息集中管理 | 定值批量下发通道 = 保护定值篡改的集中面 |
| **故障录波** | — | 变电 | 录波（COMTRADE）存储与调取 | 事后定责证据；也是数据外带目标 |

## 4. 典型设备与协议对应

| 设备 | 所在环节 | 典型协议/端口 | 权限等级 | 被利用后的直接后果 |
|---|---|---|---|---|
| **PLC** | 发电辅控、配网、站用电 | S7comm(102)、Modbus(502)、EtherNet/IP(44818)、CODESYS(1200) | 过程控制 | 逻辑被改（持久化）、停机 |
| **RTU** | 输电/变电/配电远动 | DNP3(20000)、IEC 104(2404)、Modbus | 远动汇聚 | 多装置遥控通道失守 |
| **IED**（保护/测控） | 变电 | IEC 61850 MMS(102)、GOOSE/SV(二层)、厂商专有 | **保护** | 误动/拒动、定值篡改 |
| **合并单元 MU** | 变电（过程层） | SV `0x88BA`、FT3 | 采样 | 伪造采样值误导保护 |
| **智能终端** | 变电（过程层） | GOOSE `0x88B8` | 开关执行 | 伪造跳合闸 |
| **HMI** | 全环节 | 厂商专有、OPC、Modbus、RDP | 人机监视控制 | 操作权被接管；也是 T0852 截图目标 |
| **工程师站 EWS** | 全环节 | 组态下装协议（S7 下载/上载、61850 SCL 下装）、SMB、RDP | **最高（可改逻辑与定值）** | 改逻辑 + 工程文件污染（T0873/T0889） |
| **远动网关 / 通信管理机** | 变电/配电 | 多协议转换（Modbus↔104/DNP3↔61850） | 跨域汇聚 | **横移跳板**；其管理面（Web/SNMP/Telnet）常为弱口令 |
| **前置机 / 数据采集服务器** | 主站侧 | 多协议主站栈、OPC | 全网汇聚 | 一次拿到全站点表与遥控能力 |
| **保护装置** | 变电 | IEC 61850、厂商专有、IEC 103 | 保护出口 | Loss of Protection |
| **同步相量测量装置 PMU** | 输电 | C37.118 | 测量 | 稳定判断被误导 |
| **计量表计/采集终端** | 发/输/配 | Modbus、DL/T645、上行 4G | 计量 | 结算数据失真 |
| **逆变器 / 储能 PCS** | 新能源 | Modbus、厂商云平台 | 出力控制 | 出力被限/脱网 |
| **安全仪表/联锁控制器** | 发电 | 专有、Modbus、PROFINET | **安全** | Loss of Safety |
| **交换机 / VLAN 设计** | 变电二层 | 802.1Q、组播（GOOSE/SV） | 网络基座 | 组播可见性 + 错误 VLAN 划分 = 全网可注入 |
| **横向隔离 / 纵向加密装置** | 边界 | 摆渡文件、IPSec 类 | **边界** | 边界被绕即分区失效；其管理面自身是目标 |

## 5. 各环节攻击面与业务影响

### 5.1 发电

| 面 | 说明 |
|---|---|
| 攻击面 | 厂级办公网 → 生产管理区 → DCS/SIS 的边界；工程师站远程组态；辅控系统（输煤/化水）作为低阻力入口；新能源场站的“云侧”监控平台 |
| 高价值目标 | DCS 工程师站、SIS、升压站 NCS、AGC/AVC 子站 |
| 业务影响 | 机组非计划停运（T0826）、设备损坏（T0879）、安全联锁失效（T0880）、出力受限（T0828）、发电量损失 |
| 检测抓手 | 辅控系统异常外联；DCS 侧非计划下装/在线修改；SIS 组态变更；过程量在无人操作时异常波动 |

### 5.2 输电

| 面 | 说明 |
|---|---|
| 攻击面 | 调度数据网纵向通道（纵向加密装置两侧）、变电站远动出口、线路在线监测装置（常直连 4G 且防护弱）、跨区联络线的 ICCP 通道 |
| 高价值目标 | 调度自动化前置机、EMS、PMU 集中器、ICCP 网关 |
| 业务影响 | 调度端状态估计与潮流计算被误导（T0832）→ 错误调度决策；多站联动风险；Loss of View（T0829/T0815） |
| 检测抓手 | 遥测与 PMU 相量的物理一致性（功率平衡、相角差）；同一测点多源交叉校验；ICCP 对端报文与本地记录比对 |

### 5.3 变电

| 面 | 说明 |
|---|---|
| 攻击面 | **GOOSE/SV 为二层组播**：接入站内任一台交换机端口即可监听与注入；MMS 102/tcp 免认证；SCD/CID 工程文件在后台与工程师站明文存放；站控层与过程层共网或 VLAN 划分不当 |
| 高价值目标 | 保护装置、合并单元、智能终端、站控层后台、远动网关、保信子站 |
| 业务影响 | **Loss of Protection（T0837）**：GOOSE 伪造/抑制导致误动或拒动 → 设备损坏与人身风险；Loss of Control/View；全站不可控 |
| 检测抓手 | 同一 gocbRef 出现多源 MAC；`stNum`/`sqNum` 异常；`confRev` 变更；GOOSE/SV 帧率超周波基准；MMS 侧非授权 Write/Oper；`test=1` 帧出现在生产通道 |
| 参考素材 | `IEC61850SecurityDataset` 给出 18 IED 站的三类攻击 trace 与三类业务扰动（母线保护/断路器失灵/低频减载）正常态 trace，可直接做“业务态 vs 攻击态”差分 |

### 5.4 配电

| 面 | 说明 |
|---|---|
| 攻击面 | 终端数量巨大、分布无人值守、回传链路混杂（无线专网/4G/光纤）；主站与终端之间的认证策略常不对称（主站强、终端弱）；DTU/FTU 的本地维护口（串口/网口）常无保护 |
| 高价值目标 | 配网自动化主站、大量 DTU/FTU/TTU、用电信息采集主站、充电桩运营平台 |
| 业务影响 | 馈线自动化误动/拒动、故障隔离失败、复电延迟（SAIDI/SAIFI 恶化）；大面积分散影响 |
| 检测抓手 | 终端上报与主站下发的点表/链路地址一致性；单终端高频写；非授权源对终端执行遥控；无线链路上的伪造主站特征 |

## 6. 攻击路径模式（业务视角，用于链路拓扑与报告叙事）

```
模式 A（IT → OT 纵向穿透）
办公网/钓鱼 → 工程师站或报表机（双网卡/共享） → 站控层后台 → 装置（IED/PLC/RTU）

模式 B（边界设备面）
互联网 → 暴露的监控云平台 / 远动网关 Web 管理口 → 站内网 → 远动通道 → 多站

模式 C（过程层二层注入）
站内任一接入点（检修口/辅控交换机/无线 AP） → 监听 GOOSE/SV 组播 → 伪造报文影响保护

模式 D（工程面持久化）
工程师站工程文件被污染 → 检修下装 → 多台同类装置同时“合法”变更（T0873/T0889）

模式 E（供应链/外委）
厂商远程运维通道 或 第三方组态软件更新包 → 站控层 → 全域
```

每条路径在 AttackAtlas 中登记时应带：目标环节（发/输/变/配）、分区（I/II/III）、
协议与端口、边动作（获取权限/凭据复用/隔离突破/保护影响）、业务影响技术（T0837/T0880/T0831…）。

## 7. 影响分级建议（报告定级口径）

| 级别 | 判定条件（任一） | 电力语义 |
|---|---|---|
| **极高** | 可影响保护/安全功能（IED、MU、智能终端、SIS）；可批量改定值 | 误动/拒动、设备损坏、人身风险（T0837/T0880/T0879） |
| **高** | 可对多站/多终端执行遥控；掌握全站点表与遥控能力；可改 DCS 逻辑 | 区域级控制失守（T0831/T0827） |
| **中** | 可读全量遥测/点表/工程文件；可关闭告警上送；可影响监视 | 失去监视、数据外泄（T0815/T0882/T0878） |
| **低** | 仅单点信息泄露（型号/固件版本）；无控制或观测影响 | 情报收集前置（T0888/T0861） |

定级时必须标注：**是否已证明“控制类影响”**（遥控/写定值/改逻辑），
还是仅“观测类影响”（读遥测/读工程文件）——二者报告处理与处置优先级差异极大。
